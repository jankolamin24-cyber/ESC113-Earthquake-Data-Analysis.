# ESC 113 — Earthquake Data Analysis

## Project Overview

This project uses Python to analyze earthquake data from the United States Geological Survey (USGS) for September 2026.

## Project Results

- Total earthquakes analyzed: 1,226
- Average magnitude: 4.53
- Largest magnitude: 6.7
- Average depth: 75.34 km
- Shallow earthquakes: 886
- Intermediate earthquakes: 262
- Deep earthquakes: 78

## Python Libraries

- Pandas
- Matplotlib
- python-docx

## Project Visualizations

The project includes four graphs showing earthquake magnitude distribution, magnitude versus depth, magnitude categories, and daily earthquake activity.

## Engineering Findings

Most recorded earthquakes were in the magnitude 4.0–4.9 category. The strongest earthquake had a magnitude of 6.7 and occurred near Tadine, New Caledonia, on September 25, 2026.

## Data Source

USGS Comprehensive Earthquake Catalog (ComCat).

## How to Run

Open the `.ipynb` notebook in Google Colab and run the cells in order. Internet access is required to download the earthquake dataset.
